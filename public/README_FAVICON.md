# Favicon Dosyaları

## Gerekli Dosyalar

Aşağıdaki favicon dosyalarını `public/` klasörüne ekleyin:

1. **favicon.ico** - Ana favicon dosyası (16x16, 32x32, 48x48 boyutlarında)
2. **apple-touch-icon.png** - Apple cihazlar için (180x180px)
3. **favicon.svg** (opsiyonel) - Modern tarayıcılar için SVG favicon

## Dosya Yapısı

```
public/
├── favicon.ico
├── apple-touch-icon.png
├── favicon.svg (opsiyonel)
└── site.webmanifest
```

## Not

- `site.webmanifest` dosyası zaten oluşturulmuştur
- Favicon dosyalarını ekledikten sonra tarayıcı cache'ini temizleyin
- Favicon'lar otomatik olarak yüklenecektir
