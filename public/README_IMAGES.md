# Görsel Dosyaları

## Görsel Yapısı

Görselleri aşağıdaki klasör yapısına göre ekleyin:

```
public/
├── hero/
│   └── ready-cube-hero.jpg (veya .png, .webp)
└── products/
    ├── 2x2.jpg
    ├── 3x3.jpg
    ├── 4x4.jpg
    ├── 5x5.jpg
    ├── 6x6.jpg
    ├── 7x7.jpg
    ├── megaminx.jpg
    ├── pyraminx.jpg
    ├── skewb.jpg
    └── square-1.jpg
```

## Görsel Özellikleri

- **Format**: JPG, PNG veya WebP
- **Hero görsel**: En az 1200x1200px (kare format önerilir)
- **Ürün görselleri**: En az 800x800px (kare format önerilir)
- **Optimizasyon**: Next.js otomatik olarak görselleri optimize eder

## Not

Görseller eklendiğinde otomatik olarak yüklenecektir. Görsel yoksa placeholder gösterilir.
