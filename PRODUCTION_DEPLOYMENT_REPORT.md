## 9. Custom Domain Setup

### Vercel Custom Domain

1. **Add Domain in Vercel Dashboard**
   - Go to Project Settings → Domains
   - Click "Add Domain"
   - Enter your domain (e.g., `readycube.com`)

2. **DNS Configuration**
   - **Option A: Root Domain (readycube.com)**
     ```
     Type: A
     Name: @
     Value: 76.76.21.21
     ```
   
   - **Option B: Subdomain (www.readycube.com)**
     ```
     Type: CNAME
     Name: www
     Value: cname.vercel-dns.com
     ```

3. **SSL Certificate**
   - Vercel automatically provisions SSL
   - Wait 24-48 hours for DNS propagation
   - SSL will be active automatically

4. **Verify Domain**
   - Vercel will verify DNS records
   - Status will show "Valid Configuration"
   - Site will be live on custom domain

### Netlify Custom Domain

1. **Add Domain in Netlify Dashboard**
   - Go to Site Settings → Domain Management
   - Click "Add custom domain"
   - Enter your domain

2. **DNS Configuration**
   - **Option A: Root Domain**
     ```
     Type: A
     Name: @
     Value: [Netlify IP - shown in dashboard]
     ```
   
   - **Option B: Subdomain**
     ```
     Type: CNAME
     Name: www
     Value: [your-site].netlify.app
     ```

3. **SSL Certificate**
   - Netlify automatically provisions SSL
   - Let's Encrypt certificate
   - HTTPS redirect enabled

4. **Verify Domain**
   - Netlify will verify DNS
   - Status: "DNS configured correctly"
   - Site live on custom domain

### DNS Provider Instructions

**For GoDaddy, Namecheap, etc.:**
1. Log into your domain registrar
2. Navigate to DNS Management
3. Add the records shown above
4. Save changes
5. Wait for propagation (24-48 hours)

## 10. Deployment Steps

### Vercel Deployment

1. **Prepare Repository**
   ```bash
   git init
   git add .
   git commit -m "Production ready"
   git remote add origin <your-repo-url>
   git push -u origin main
   ```

2. **Deploy to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Click "Import Project"
   - Connect GitHub/GitLab/Bitbucket
   - Select repository
   - Vercel auto-detects Next.js
   - Click "Deploy"
   - Wait ~2 minutes

3. **Verify Deployment**
   - Check build logs for errors
   - Visit deployment URL
   - Test all pages
   - Verify functionality

4. **Add Custom Domain** (Optional)
   - Follow "Custom Domain Setup" above
   - Wait for DNS propagation
   - SSL auto-provisioned

### Netlify Deployment

1. **Prepare Repository** (same as above)

2. **Deploy to Netlify**
   - Go to [netlify.com](https://netlify.com)
   - Click "Add new site" → "Import an existing project"
   - Connect Git provider
   - Select repository
   - Netlify uses `netlify.toml`
   - Click "Deploy site"
   - Wait ~3 minutes

3. **Verify Deployment**
   - Check deploy logs
   - Visit site URL
   - Test functionality

4. **Add Custom Domain** (Optional)
   - Follow "Custom Domain Setup" above
